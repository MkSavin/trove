Generated `<!-- trove:items|documents|counts|placement … -->` blocks in any hand-written document, refilled on every edit and report, frozen once archived, with a `filter:` header as their base. Summaries become kinds: `trove summary new <kind>` creates a dated `summary` document from the kind's template with blocks filled and `<!-- write: … -->` places for the analysis (`write-place` rule); `trove summary show` prints one without writing. Rebase conflicts inside generated blocks settle themselves.
