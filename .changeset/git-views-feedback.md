`trove:branches` shows each branch once, preferring the remote-tracking ref and marking a local branch that is ahead or diverged, adds an `own` column of commits in none of the bases, and hides branches merged into every base unless `merged=true|any`. `trove:changes` shows items closed as `moved` as moved, with the new id in `to`; supports `group=change|document` and `as=counts` with an optional `by`; and `since=previous` never picks the summary itself, a same-day sibling or a predecessor git mistakes for a rename. Labels of these blocks a config leaves out come in its `language`.
